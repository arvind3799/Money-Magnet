Import trades from MT5

  1. Open MetaTrader 5 on your computer and log in to your account.
  2. Open the History tab at the bottom (Toolbox, or press Ctrl + T).
  3. Right-click inside it, choose the period (for example All History or Last 3 months).
  4. Right-click again → Report → HTML (or Open XML), and save the file.
  5. Drop that file below.

Only closed positions are imported. P&L includes commission and swap. Trades you already imported are skipped, so you can import again any time.
